💰 WE-Budget

A Smart Financial Management Application

📌 Overview

WE-Budget is a financial management application designed to help users track their expenses, create structured savings plans, and receive intelligent investment suggestions.

The application enables individuals to gain better control over their finances through data-driven insights, budgeting tools, and goal-oriented planning.

🚀 Features
1️⃣ Expense Tracking

Add, edit, and delete transactions

Categorize expenses (Food, Rent, Travel, Utilities, etc.)

Real-time balance updates

Monthly and weekly spending analysis

2️⃣ Budget Planning

Create custom budgets for different categories

Set monthly spending limits

Track budget utilization

Alerts for overspending

3️⃣ Savings Planner

Define financial goals (e.g., Emergency Fund, Vacation, Gadget Purchase)

Calculate required monthly savings

Track progress towards savings goals

4️⃣ Investment Suggestions

Provides basic investment recommendations

Suggests options based on savings capacity

Helps diversify investments (e.g., Fixed Deposits, Mutual Funds, SIPs, etc.)

🏗️ Application Structure

The application consists of the following main pages:

Home – Dashboard with financial summary

Account – User profile and account details

Plans – Savings and investment planning

Library – Financial resources and investment knowledge

📊 How It Works

User registers and logs in.

Adds income and expense transactions.

Application calculates total balance and spending trends.

User sets savings goals.

System suggests investment options based on financial behavior.

Dashboard provides real-time financial insights.
